## Ordered steps
1. **Toolchain** — root `package.json`, configs, `.gitignore`, `.nvmrc`, empty workspace
   skeletons, `npm install` with pinned versions → `npm run lint|typecheck|format:check` pass on nothing. `[plan 0001/1]`
2. **Domain, BR-1** — `result.ts` (`{ok,value}|{ok:false,error:{code,message}}`), `calendar-date.ts`
   (parses `YYYY-MM-DD` and rejects malformed or non-existent dates via a `Date.UTC` round-trip),
   `working-days.ts` (`countWorkingDays(start, end)`: INVALID_DATE first, then BR1_END_BEFORE_START,
   then counting Mon–Fri inclusive with UTC methods, then BR1_NO_WORKING_DAY when 0), plus unit tests. Tests are written first and seen red. `[plan 0001/2]`
3. **API health** — `buildApp()` registers `GET /api/health` → `200 {"status":"ok"}` with no auth
   hook. Integration test via `app.inject()` asserts status and the exact body (deep equal: no extra
   fields) and closes the app afterwards. `server.ts` is the only file that listens. `[plan 0001/3]`
4. **Web start page** — `StartPage` fetches `/api/health` once on mount: `role="status"` region
   shows "Checking service…" → "Service: OK" (2xx and `status==="ok"`) or "Service unavailable"
   (network error, non-2xx, or another body). Title "Leave Manager". Component tests stub `fetch`:
   pending, ok, 500, rejected. Vite proxy, `tools/dev.mjs`, `npm run dev`. `[plan 0001/4]`
5. **Boundaries** — `eslint.config.js` rules: domain forbids `fastify`, `react*`, `node:*`/`fs`/`http`/`net`,
   `@leave/api`, `@leave/web`, `Date.now()` and argument-less `new Date()`. Web forbids `@leave/api`
   and allows only `import type` from `@leave/domain`. `apps/api/src/routes/**` forbids
   `**/repository/**` and `node:sqlite`. Deep imports `@leave/*/src/**` are forbidden everywhere.
   `tools/lint-boundaries.test.ts` uses the ESLint API `lintText(code, { filePath })` with one
   snippet per rule (expects the error) plus an allowed snippet per area (expects none). `[plan 0001/5]`
6. **Contract on** — uncomment `check.conf`, CI Node setup, the docs above. Run `dash ./scripts/check`
   full and `--fast` 3× each (median per profile), `./scripts/residue` + `--fast`, and the test-count
   check (fast count + int count = `vitest run` total). Record Build evidence and push. `[plan 0001/6]`

## Risks & open questions
1. **TypeScript 7 vs typescript-eslint.** `typescript-eslint@8.72.2` requires `typescript >=4.8.4 <6.1.0`;
   `latest` is 7.0.2. *Recommendation:* pin `6.0.3` and record it in conventions; upgrading is its own spec once typescript-eslint supports 7.
2. **Running the API in dev without a build step.** The plan uses Node 26's built-in TypeScript
   stripping (`node --watch apps/api/src/server.ts`, `erasableSyntaxOnly` in tsconfig) across the
   workspace symlink to `@leave/domain`. A probe was blocked by the session's sandbox, so it is unverified.
   *Recommendation:* try it in step 4. If it fails, add `tsx` (MIT, dev-only) through an amendment rather than silently.
3. **The fast/full selector with Vitest projects.** Fast = `vitest run --exclude "**/*.int.test.ts"`,
   full-only = `vitest run .int.test.` (a path filter). *Recommendation:* step 6's test-count check proves
   fast ∪ int = all, with nothing counted twice or missed.
4. **Environment (R-13).** doctor today: 0 fail, 1 warn (no steps yet), so no per-profile verdict.
   Planner machine: Node 26.13.1 and npm 11.20.0 meet the planned `requires` lines (Node 26, `node_modules`
   after `npm ci`), so I expect **both profiles runnable here**. Locally, check and doctor run via `dash` (B-1). CI runs Ubuntu `sh`.
   *Recommendation:* accept. BUILD compares doctor's verdict with this line.
5. **Docs conflict (R-10).** `docs/conventions.md` says the walking skeleton confirms `node:sqlite`, but
   this spec has no database (out of scope). *Recommendation:* reword the conventions line so the first spec
   that persists data confirms it (step 6 docs). There's no ADR now, because there is no decision to record yet.
6. **UI screenshots at VERIFY** (AC-6…8) need a headless browser outside the repo (Playwright in a
   temp dir, with a ~150 MB browser download), stubbing `/api/health` via route interception for each state.
   *Recommendation:* accept. Fallback: the Chrome extension, with the human capturing only if both fail.
7. **`TZ=UTC` in npm scripts** is POSIX syntax. The team uses macOS and Linux only. *Recommendation:* accept.
